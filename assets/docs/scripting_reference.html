uChip Scripting Reference

A uChip script is a Python file. Place it on the chip as a program: its parameters appear as settings, and its functions can be shown as buttons. Everything in the scripting API is available without importing anything, and all standard Python modules can be imported as usual.

Hover over an API name in the editor to see its documentation, and press Ctrl+Space for suggestions.

Contents: Functions · Waiting · Parameters · Valves · Other programs · Logging and description · Full API

Functions

A script can define any number of functions. Use the @display decorator to show a function as a button on the program. Only functions with no arguments can be shown.

@display
def CloseValves():
    FindValve("Inlet").Close()
    FindValve("Outlet").Close()

@display("Open everything")   # Changes the button text.
def OpenAll():
    ...

Functions without @display can still be called from other functions, or from other programs.

Waiting: background functions

A function that yields a wait runs in the background: uChip keeps running other functions while it waits, and the program shows pause and stop buttons for it.

@display
def Rinse():
    rinse = FindValve("Rinse")
    rinse.Open()
    # Also WaitForMinutes(m) and WaitForHours(h).
    yield WaitForSeconds(30)
    rinse.Close()

Never wait with a plain loop or time.sleep: that blocks every program until it finishes. Yield inside long loops instead.

To run cleanup when a background function stops, pauses or resumes, use the @onStop, @onPause and @onResume decorators:

def ClosePump():
    for valve in pumpValves.Get():
        valve.Close()

@onStop(ClosePump)
@onPause(ClosePump)
@display
def RunPump():
    while True:
        ...
        yield WaitForSeconds(0.5)

Parameters

Parameters are settings the user can change on the program, such as a number, some text, a valve or a list of valves. Declare them at the top level of the script (not inside a function), and read them with .Get().

rinseTime = Parameter(float, defaultValue=1, minimum=0.1, maximum=20)
rinseValve = Parameter(Valve, displayName="Rinse valve")

@display
def Rinse():
    valve = rinseValve.Get()
    valve.Open()
    yield WaitForSeconds(rinseTime.Get())
    valve.Close()

Parameter(type) types: int, float, str, bool, Valve and Program.

Dropdowns

.Get() returns the text of the chosen option.

direction = OptionsParameter(["Forward", "Reverse"])

@display
def RunPump():
    if direction.Get() == "Forward":
        ...

Lists

inlets = ListParameter(Valve, displayName="Inlet valves")

@display
def CloseInlets():
    for valve in inlets.Get():
        valve.Close()

A script can also change a parameter with .Set(value).

Valves

Get a valve by name with FindValve(name), or let the user pick one with Parameter(Valve).

inlet = FindValve("Inlet")
inlet.Open()
inlet.SetOpen(not inlet.IsOpen())   # Toggle.
Log("%s is on solenoid %d" % (inlet.Name(), inlet.SolenoidNumber()))

Other programs

Get another program on the chip by name with FindProgram(name), or let the user pick one with Parameter(Program). Its functions and parameters are available by their names in its script.

Given a program named Chip Functions with this script:

def SetRinse(open):
    FindValve("Rinse").SetOpen(open)

another program can use it like this:

@display
def DoRinse():
    functions = FindProgram("Chip Functions")
    functions.SetRinse(True)
    yield WaitForSeconds(15)
    functions.SetRinse(False)

Another program's background functions can be controlled with .IsRunning(), .Pause(), .Resume() and .Stop(), e.g. FindProgram("Pump").RunPump.Stop().

Logging and description

SetDescription("Rinses the chip with buffer.")   # Shown in the inspector.

@display
def Check():
    Log("Inlet is " + ("open" if FindValve("Inlet").IsOpen() else "closed"))
